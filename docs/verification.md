# 验证记录与实际边界

## 云端验证

Actions执行Go vet/race/单元与真实PostgreSQL事务测试、TypeScript严格检查、Lint、前端构建。随后在ubuntu-24.04和ubuntu-24.04-arm原生构建与启动API/Worker/数据库，真实文件上传、报价、队列、额度和排版均由Go服务处理，只有外部模型与采集服务由测试桩模拟。

浏览器验收包括新用户商品空状态、真实文件选择、第二件商品生成、默认展示、13点带货、同键重放、商家隔离、部分失败、结果未知、文案轮询保护、更新排版与ZIP下载、异步选题导入、360px溢出，以及各尺寸截图。

截图Artifact：ui-screenshots-amd64 / ui-screenshots-arm64；完整测试报告另存于 evidence-amd64 / evidence-arm64。截图固定视口为1440×1000、1024×768、390×844；360px检查长商品名、长卖点和图片失败。等待报价、排版状态及图片加载稳定后截图。成功编译不代替视觉评审。

Go PostgreSQL测试验证12个并发重复提交、唯一预占/结算、第二件商品关联、过期报价、租户隔离、真实PNG ZIP与最新文案。提交SHA和Actions链接以GitHub运行实际结果为准，不将未完成运行写成通过。

## 真实外部接口尚需验收

用户没有提供商用图片/文字接口或采集身份。CI验证协议与闭环，不验证真实服装印花、色差、包装保真或抖音反爬稳定性；本项目也没有在生产服务器上线。

配置后至少使用服装、家居、美妆三个类目各10件自有商品，每件记录：
- 参考照片、生成版本、选用/放弃原因。
- 颜色、形状、Logo、标签、印花、包装偏差。
- 通过人工审核的采用率、重试次数、供应商用量与可靠账单。
- 主图与场景图的清晰度、完整主体；长文字排版不溢出。
- 真实异步采集任务和缺失/回退计数，接口不可用时展示包仍工作。

连通性检测不声称已验证模型生成。估算成本与实际费用分别存储，缺少可信计费来源时实际费用保持null。
