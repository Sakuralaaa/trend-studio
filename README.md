# Trend Studio

独立的 Go 电商图片与内容创作平台。React 前端采用用户提供的 Gemini 界面方向并接入真实 API；不依赖衣序代码、数据库或存储。

商家流程：邀请码激活 → 上传商品参考图 → 默认生成商品展示 → 查看作品、免费改文案和更新排版 → 下载真实 PNG 与文案 ZIP。热点是可选灵感来源。

- 商品展示：2 次图片编辑、1 次文本模型；主图、场景图、1080×1080 卖点图及文案，初始 23 点。
- 抖音带货：1 次图片编辑、1 次文本模型；场景图、1080×1920 封面、3 条标题、口播脚本及发布文案，初始 13 点。
- 私有参考图与素材、商家隔离、服务端报价、持久化队列、租约、额度预占/结算/退还。
- 明确失败释放预占；请求已发送但结果未知时待人工核实，不自动重发收费调用。
- PostgreSQL 17；Go 1.27.1 / Chi / pgx；React / Vite / Tailwind / TanStack Query / URL 路由。
- 行业账号监控及链接导入适配 Evil0ctal v5.1.3。不是官方全站热榜，不声称完播率或成交数据。

## 验证与发布

本项目不在用户电脑安装依赖、编译或运行测试。`Prepare dependency locks` 工作流在云端生成依赖锁与格式化源码，取回提交后才能发布。`Validate and publish` 执行源码检查、真实 PostgreSQL 测试、race 检查、前端检查、amd64/arm64 原生容器启动与浏览器操作，并上传截图。

发布使用容器验证阶段保存的镜像，不重新构建。镜像：`ghcr.io/sakuralaaa/trend-studio:sha-<完整提交SHA>`。`latest` 仅指向 main 当前最新通过版本；生产使用 SHA 或摘要。PR 不发布镜像。

## 外部接口

管理员配置文字与图片接口各自的地址、模型、密钥、参考图字段、能力和超时。图片必须支持真实参考图编辑；未配置时界面明确显示原因，不提供模拟结果。

仓库的 `cmd/test-provider`、`tests`、`web/e2e` 仅用于 CI。测试服务不会进入运行镜像，测试凭据不得用于生产。真实图像保真度、采用率和真实费用需要配置商用接口后另行验收。
